# All content exists as real HTML (Plain View)

Every Section's content ships as semantic HTML at its own URL; the simulation is a layer on top, never the only carrier of content. Canvas-only content would be invisible to screen readers, search engines, and LinkedIn/Slack link previews, and a recruiter on a slow phone must still see the content. This also means the simulation can always be switched off (`prefers-reduced-motion` or a visible toggle) without losing anything.
